Hotel-WebApp to prosta strona internetowa umożliwiająca logowanie oraz rezerwację pokoi w hotelu
## DEMO
https://youtu.be/Njk9nd5GJx4

## Funkcjonalności
-Rejestracja/ logowanie
-Rezerwacja wizyt w hotelu
-Podgląd historii wizyt

## Technologie
-ASP.NET CORE
-ENTITY FRAMEWORK
-STRIPE
-SQL SERVER
-TAILWINDCSS
